# TaskFlow-Python 📝🐍

**TaskFlow-Python** is a comprehensive task management application built in Python. It provides both a **Command-Line Interface (CLI)** and a **Graphical User Interface (GUI)** for seamless task management. TaskFlow enables users to efficiently add, update, delete, and manage tasks with advanced features such as deadlines, notifications, priority sorting, and data persistence using SQLite.

---

## Features ✨

- 🖥️ **Dual Interface**: Access the application via **CLI** for quick operations or **GUI** for an intuitive experience.
- 📋 **Task Management**: Create, update, delete, and view tasks seamlessly.
- ⏰ **Deadlines & Notifications**: Set deadlines for tasks and receive timely notifications for those nearing their limits.
- 🔝 **Priority Sorting**: Assign priorities to tasks and sort them by priority.
- 💾 **Data Persistence**: Securely store tasks using SQLite for consistent data handling.
- 🔄 **Import/Export**: Import tasks from or export tasks to JSON and CSV formats for data portability.
